# Troubleshooting

## Robot Offline

### Possible Causes

- Robot is powered off
- Network connection failure
- Maintenance mode enabled

### Resolution

1. Verify power status.
2. Confirm network connectivity.
3. Check maintenance settings.
4. Restart the robot if necessary.

---

## Task Assignment Failed

### Possible Causes

- Invalid robot ID
- Robot unavailable
- Task queue limit reached

### Resolution

1. Verify robot availability.
2. Check task queue status.
3. Retry task assignment.

---

## Authentication Failed

### Possible Causes

- Expired API key
- Incorrect authorization header

### Resolution

1. Verify API credentials.
2. Regenerate API key if necessary.
3. Confirm Bearer Token format.
